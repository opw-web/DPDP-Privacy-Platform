Privacy Demo — the seven buttons

Looking for the full walkthrough? Double-click 2 - Demo Runbook, or open docs/demo-runbook/RUNBOOK.html. It covers everything from switching the laptop on to shutting it down, with screenshots and a line to say at each step. This page is only the button list.

Guide for prospective clients: open docs/demo-runbook/CLIENT-GUIDE.html. It uses the same product journey and screenshots as the presenter runbook, but is written for clients to explore the sample environment themselves.

Sending either guide to someone? Use RUNBOOK-standalone.html or CLIENT-GUIDE-standalone.html. Every screenshot is embedded inside those files, so the recipient only needs the one HTML file.

These seven icons are on your Desktop and in your applications menu, numbered in the order you use them. Double-click one, a black window pops up and tells you what it is doing in plain English — wait for it to finish, then press Enter to close it.

1 Start Privacy Demo
Turns everything on and opens the demo in your web browser when it is ready. Safe to click even if it is already running. About two minutes.
2 Demo Runbook
Opens the full step-by-step demo guide in your browser. Works whether or not the demo is running.
3 Open Database
Opens a table browser so you can look inside the database itself — click a table name, see its rows. No SQL, no terminal.
4 Show Demo Proof
Counts the live demo data and shows the numbers in a window you can point at, next to the numbers that were expected.
5 Demo Status
Shows what is on and what is off, and the web address for each part, without changing anything.
6 Stop Privacy Demo
Turns everything off cleanly. Your demo data is kept, so Start brings it back exactly as you left it.
9 Reset Demo to Fresh State
Destroys all demo data and rebuilds it from scratch, including all the notices, consents, requests and the breach the demo needs. It asks you to confirm first. Takes about twelve minutes — never run it during a demo.
