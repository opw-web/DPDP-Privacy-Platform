Privacy Demo — the four buttons

These four icons are on your Desktop and in your applications menu. Double-click one, a black window will pop up and tell you what it's doing — just wait for it to finish, then close it (or press Enter when it says you can).

▶ Start Privacy Demo
Turns everything on and opens the demo in your web browser when it's ready. Safe to click even if it's already running.
⏹ Stop Privacy Demo
Turns everything off cleanly. Your demo data is kept, so Start will bring it back the way it was.
⟳ Reset Demo to Fresh State
Wipes the demo data and rebuilds it from scratch, ready for a fresh walkthrough. This asks you to confirm before it deletes anything — it takes a few minutes, so start it before you need it.
ℹ Demo Status
Shows what's on and what's off, and the web addresses for everything, without changing anything.

Sign in to the demo with admin@acmeretail.demo / Password123!.

Nothing here requires typing a command — if a button ever fails, the window will tell you in plain English what happened before you close it.
